# assembly_v3 实现与验收记录

本文件区分可运行的软件流程与已验收的模型。当前所有新模型为实验草稿，不能作为已完成精细复刻销售或发布。

## 已实现

- 车辆物理资料：生成前采集、22 类测量字段、单位/角度基准、年款与来源匹配、冲突保留和任务快照。整车尺寸进入比例网格，部件目标进入规划与真实轮胎尺寸检查。详情页显示来源与缺失项；PDF/蓝图自动标定、门板/玻璃表面精确求解仍未实现。见 `vehicle-physical-specifications.md`。

- `scene.py` 统一零件实例、刚体变换、模块依赖图、连接、关节和搭建步骤。拒绝缩放、反射、非正交矩阵及无效引用。

- NetworkX 连通检查；从同一承重结构根节点检查全车连接。
- 原生碰撞盒 SAT 检查；轮毂/轮胎的内嵌几何只在对应 fixed 连接证明存在时允许重叠。

## 操作

默认 `DESIGN_WORKFLOW=assembly_v3`。环境变量：`ASSEMBLY_TEXT_CALL_LIMIT=64`、`ASSEMBLY_MODULE_REPAIR_LIMIT=3`、`ASSEMBLY_REPLAN_LIMIT=2`、`ASSEMBLY_LEASE_SECONDS=900`。生图不设预算上限，任务只记录实际生图调用次数；文本调用仍受默认上限保护。

API：`POST /api/v1/designs/{id}/control/pause|resume|cancel|retry?module=...`。完成生成但验收失败的草稿使用模块 retry；不自动修改历史设计。修改比例或定制会创建新设计。

真实参考图复用的样板脚本：在 backend 目录运行 `python -m tasks.build_f40_samples --references <已有 F40 设计 UUID>`。它调用配置的文本模型做视觉规划，导出三个比例的草稿并保存独立质量报告，不额外冒充生图或物理验收。
